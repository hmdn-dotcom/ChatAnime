# ChatAnime
A simple project about chat or user interaction with other users in a server environment, created with high and strict security.

## Available features
### 1. You can send a friend request before chatting. 
Before chatting, both users must establish a friendship relationship, where you can send a request to your friend to become friends. When your friend accepts, you can immediately start chatting. And of course, to find friends, you can use the search feature by entering your friend's ID or nickname, then sending a friend request.

### 2. Safe and transparent chat 
The chats you have with your friends are securely protected, so that no one outside the conversation knows what you are discussing. For now, you can only send chats to your friends. Sending images or other files may be added in the next update.

### 3. Report and block
If you find a friend or user who makes you uncomfortable or makes you feel uneasy, you can block that user. And also if the user carries out illegal or unlawful actions or commits verbal harassment, you can report it to our team so we can check and ban the account. For now this feature is not available, of course the next update will add it
